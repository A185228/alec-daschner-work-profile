# Repository guide

This existing repository is consolidated around Alec P. Daschner's author identity.

- README.md: author identity and official reading links.
- CONTACT.md: author correspondence.
- CHANGELOG.md: dated maintenance decisions.
- Other retained Markdown paths: retirement notices for previous work-profile material.

## Maintenance rules

Use one focused branch and reviewed pull request per maintenance change. Record the confirmed defect, correction, checks and consequences. Keep originals recoverable in Git history.

Preserve separate English and Afrikaans author URLs. Do not add public sites, promotional pages, invented testimonials, unverified prices or tracking.

This repository has not been established as source for either live app. Do not upload the shared local workspace, manuscripts, private records, database exports or credentials. Do not add automatic deployment here.

Live apps retain their existing release gates. Jeanette Basson's authorship remains separate from Alec's technical preservation work.
